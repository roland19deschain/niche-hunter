# Bundled report fonts

Unmodified Noto Sans Regular and Bold from https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans . Copyright belongs to The Noto Project Authors. Distributed under SIL Open Font License 1.1; see OFL.txt. Embedded subsets in exported reports do not change the report content license.

These fonts provide the default text coverage, not a target market or report language. For other scripts, select suitable fonts with the PDF export options or use the calling client's native PDF renderer.
