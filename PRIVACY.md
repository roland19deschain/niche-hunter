# Niche Hunter data handling

Niche Hunter is a local skill/plugin and Python helper. It does not operate a hosted analytics backend or maintain a central database of users' research.

- The calling AI client processes research requests and tool responses under that client's policies and settings.
- Selecting ChatGPT/OpenAI Signals lets the helper download a fixed public data release from OpenAI. This is aggregate published data, not access to private ChatGPT conversations.
- Selecting TikTok with an authorized connection sends research keywords, topic IDs, and tool parameters to the third-party TokConnect service. TokConnect and its authentication provider process those requests under their applicable policies. Review those policies and consent screens before connecting. Do not include confidential product or customer information in search terms.
- OAuth credentials are handled by the AI client's connection facilities. An owner can separately supply a TokConnect API key to a recipient, who enters it outside chat. The optional `setup_access.py` command reads that key through a hidden, user-operated terminal prompt and saves it in private Codex/Claude Code settings. These files contain plaintext credentials with owner-only POSIX permissions; they are not an encrypted vault. Native Claude connector fields use that client's credential storage and cloud connection facilities instead. No provider account or key is included in the plugin.
- Collection, normalization and report scripts do not read provider credentials. The separate setup command sends no network requests, prints no keys and does not put them into command arguments, plugin files, reports or captures. The recipient controls local settings; key holders share the owner's provider access and allowance. Removing local settings does not revoke the provider key.
- Reports, JSON results, and permitted captures are written to the caller's chosen local paths, outside the plugin cache. They may contain search phrases and source summaries. The calling agent may read those artifacts to perform analysis; they are not automatically uploaded to a Niche Hunter server.
- Local artifacts are not deleted automatically. The caller controls their storage, sharing, and removal and must follow source-specific retention and reuse terms. Research directories are ignored by this repository's Git configuration; review exports before sharing or committing them elsewhere.

TokConnect connection and account information: [connection documentation](https://tokconnect.com/connect/), [account application](https://app.tokconnect.com/). Public availability of data does not by itself grant redistribution rights. For caller-directed local TikTok processing, the skill does not require a terms URL or a permission declaration. Optional source metadata can be retained without inventing legal assurances; publication or redistribution is a separate caller action.
